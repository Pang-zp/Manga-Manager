# Manga-Manager



漫画管理器
你是否有在线看漫画卡顿，要加载很久才出来的烦恼，直接下载下来，又会和其他的PDF文件混淆，不方便查看。 那么你可以尝试下载一下这个app,你可以直接通过分享把漫画传输进来，然后进行浏览。当然，你提前下载好，传进去，在没有网的环境下（坐飞机等），浏览起来很方便。

###主要功能：                                                                                                                                                     
1.可以直接预览第一页                                                                                                                                                              
2.支持关键字搜索相应的漫画                                                                                                                                                                        
3.支持一次分享多部漫画
4.长按删除相应漫画                                                                              

###注意                                                             
1.漫画格式需为PDF或php                                           
2.记得打开软件的内存权限（照片和视频权限）                                                         
3.安装包在Release里面                           

###使用小tip                                                  
1.漫画浏览时点击屏幕会出现进度条，你可以通过它跳转相应页面                                                                       
2.在主页，一次滑动到一定程度，会出现按钮，点击它，可以直接跳转到顶部                              
3.分享到app后，就可以把下载下来的PDF删掉了，因为漫画已经保存到了app里面（手机内存多请忽略！！！）
