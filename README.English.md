# Manga Manager

Are you tired of laggy online comics that take forever to load? Or struggling with messy PDF files that are hard to distinguish? Try this app! You can directly import comics via sharing and browse them conveniently.

Moreover, if you have downloaded comics in advance, you can enjoy offline reading without any network (such as on a plane).

## Main Features
1. Preview the first page directly.
2. Search for corresponding comics by keywords.
3. Share multiple comics at once.
4. Long press to delete unwanted comics.

## Notes
1. The comic format must be **PDF** or **PHP**.
2. Remember to grant the app **storage permission** (Photos and Videos permission).

## Tips
1. A progress bar will appear when you tap the screen during browsing, which you can use to jump to a specific page.
2. On the homepage, when you swipe to a certain position, a button will appear. Tap it to jump directly to the top.
3. After sharing comics into the app, you can delete the downloaded PDF files (feel free to ignore this tip if you have enough storage space!).
